### 最近在做

整理一套自己的 **Codex Skills 合集**，把 AI 辅助工作的方法变成可复用的能力。目前从画图开始：

- **灵绘出图**：把内容整理成信息图、流程图或架构图，直接交付 PNG 和 SVG。
- **飞书灵绘**：把内容画进飞书文档，保留可编辑的文字、卡片和连线。

两种方式都支持 36 套风格，按使用场景选择。
